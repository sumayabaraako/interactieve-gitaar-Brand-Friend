# Interactieve Gitaar – POC 1

Dit is mijn eerste POC voor Brand a Friend. In deze POC test ik de belangrijkste interactie van mijn interactieve gitaar.

## Wat test ik?

In deze eerste versie test ik of:

- het plectrum met de muis kan bewegen;
- de code herkent wanneer het plectrum over één snaar gaat;
- de snaar daarna kort beweegt;
- er op dat moment geluid wordt afgespeeld.

## Techniek

Voor deze POC gebruik ik:

- HTML voor de onderdelen op de pagina
- CSS voor de styling en animatie
- JavaScript voor de interactie
- Pointer Events voor het bewegen van het plectrum
- getBoundingClientRect() om te herkennen wanneer het plectrum de snaar raakt
- Web Audio API voor het geluid

## Resultaat

De eerste POC werkt met één interactieve snaar. Wanneer het plectrum over deze snaar gaat, beweegt de snaar kort en wordt er geluid afgespeeld.

## Volgende stap

Mijn volgende stap is om de POC verder uit te werken richting mijn Figma-design en uiteindelijk meerdere snaren interactief te maken.
